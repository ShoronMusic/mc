# NotebookLM 用：洋楽AIチャット「楽しみ方」プレゼン資料プロンプト

このファイルは **Google NotebookLM** にソースとして追加し、**「洋楽AIチャットの楽しみ方」** を説明する **プレゼン資料（スライド）** の構成案・台本・スピーカーノートを生成させるための材料です。

- サイト上の説明ページ `/guide/enjoy` と、原稿 `docs/洋楽AIチャットの楽しみ方01.txt` をベースにしています。
- 宣伝用の短尺 CM 向け素材は別ファイル `docs/NotebookLM用-宣伝動画素材.md` を参照してください。

---

## 1. NotebookLM への渡し方（手順）

1. NotebookLM で新規ノートブックを作成する。
2. **ソース**に次を追加する（推奨順）:
   - **本ファイル**（`NotebookLM用-楽しみ方プレゼン.md`）
   - `docs/洋楽AIチャットの楽しみ方01.txt`（原稿・箇条書き）
   - （任意）`docs/pr-beta-feature-brief-ja.md`（β版 PR 概要）
   - （任意）画面キャプチャ・ロゴ（`videosozai/music_ai_chat_logo.png` 等）
3. 下記 **セクション 8「コピペ用プロンプト」** のいずれかを NotebookLM のチャットに貼り付けて実行する。
4. 出力されたスライド案を Google スライド等に転記し、必要に応じてスクショを差し込む。

| 項目 | 内容 |
|------|------|
| **目的** | 初めての人が「何ができて、どう始めれば楽しいか」を **5〜10分** で理解できること |
| **聴衆** | 洋楽に興味があるがサービス未体験の人／友人を部屋に誘いたい常連／イベント案内をする主催者 |

## 3. サービス一言（オープニング用）

- **名称**: 洋楽AIチャット（β版）
- **一言**: YouTube の洋楽を、**チャットルームで同時に聴きながら交流**できる Web サービス。会話の流れに合わせて **AI が選曲の進行・曲の解説・音楽の質問** をサポートする。
- **2つの楽しみ方（冒頭で必ず見せる）**:
  - **みんなでワイワイ** — 友達や初対面の人と同じ部屋で、順番に選曲しながら感想・クイズ・お題で盛り上がる。
  - **ひとりでじっくり** — 自分で会を立てて一人入室。AI 解説を読みながら `@` で深掘りし、お気に入りやマイリストに残す。

## 5. 章別：載せる本文（NotebookLM ソース用）

以下はスライドの **箇条書き原稿** としてそのまま使える。

### 5.1 使い方は簡単！3ステップ

1. **チャットルームを選んで入室** — トップの開催中から入るか、ログインして会を開始。ゲスト参加可。
2. **聴きたい曲を選曲** — YouTube の URL を発言欄に貼って送信（基本）。ライブラリから選ぶ方法もある。
3. **曲の動画（PV 等）を視聴** — 部屋の全員が同じタイミングで再生。視聴しながらチャット。

### 5.2 チャットルームならでは楽しみ方

1. 選曲は**順番制**。再生中は参加者**同時視聴**。
2. 視聴しながら**テキストで会話**。
3. **趣向や年代の違うユーザー**との出会い。選曲が会話の入口になる。
4. **選曲しない**で視聴と会話だけの参加も可能（聴き専OK）。

### 5.3 マルチデバイスとユーザー登録

- PC・タブレット・スマホで利用可能（ブラウザ）。
- メールまたは Google 認証で**ユーザー登録** → 履歴・お気に入り・マイリストが残る。
- 登録なしの**ゲスト参加**も可能。

### 5.4 便利な AI サポート機能

1. 選曲の**順番を AI が先導**（場が止まりにくい）。候補リストも使える。
2. 曲の**解説を AI が短いコメント**で紹介（曲解説）。
3. 発言の先頭に **`@` を付けると AI に質問**（洋楽・音楽関連）。

### 5.5 愉快な AI エージェントも参加（β・試験）

1. ユーザーに交じり **AI エージェントも選曲参加** することがある。
2. 時々 **会話に AI エージェントが入る**（合いの手・補足）。
3. **一人のときの相棒**として楽しめる。

### 5.6 曲を視聴しながら楽しめる機能

1. 曲解説のあと、同じ曲の文脈で **三択クイズ**（条件により・β）。
2. いま流れた曲をもとに **次に聴く候補を AI が提案**（β）。
3. **曲とアーティストの基本情報**を表示（年代・スタイル等）。
4. **視聴履歴・年代・スタイル分布**で、途中参加でも流れが分かる。

### 5.7 ユーザー同士で共同作業（β）

- **お題プレイリスト・ミッション** — クリスマス等のテーマに沿って曲を登録。部屋で「お題曲送信」するとお題向けの AI 講評も。

### 5.8 豊富な曲ライブラリ

- キーワードで曲・アーティストを**検索**。
- **アルファベット索引（A–Z）**でアーティスト別の曲一覧から選べる。
- 選んだ曲を**そのまま再生**して選曲（YouTube を行き来しない）。

### 5.9 自分用に記録できるマイページ（要ログイン）

- 選曲した曲の**履歴保存**。
- **お気に入り**・**マイリスト**への曲登録。
- **公開プロフィール**で自己紹介。

### 5.10 その他オーナー機能（主催者向け）

- 主催部屋の**名前・PR 文**の掲載。
- 部屋に**鍵**（新規参加締切）。
- **迷惑ユーザーの強制退出**（オーナー）。
- 登録ユーザーは**同時に最大 2 部屋**まで主催可能。

## 7. トーン・表現ガイド

**推す言葉**

- 同時に聴く、語れる、部屋、順番に選曲、はじめてでも、みんなで／ひとりでも、洋楽の出会い、ライブラリで探す

**控えめに**

- 「最高」「革命」などの断定、AI の万能表現、根拠のない数値（チャート順位・利用者数）

**注記（末尾またはフッター）**

- 本サービスは **β版**。機能は変更される場合があります。
- **AI の回答は参考用**です。重要な事実は公式情報でご確認ください。

## 8. コピペ用プロンプト（NotebookLM チャットに貼る）

### プロンプト A：標準プレゼン（18〜22スライド）

```
添付ソースをもとに、「洋楽AIチャットの楽しみ方」について
初めての利用者向けのプレゼン資料を日本語で作成してください。

【条件】
- スライド枚数：18〜22枚
- 各スライドに：タイトル、箇条書き（3〜5点）、スピーカーノート（30〜60秒分）
- 構成はソースの「スライド構成案」に沿う
- 冒頭で「みんなでワイワイ」と「ひとりでじっくり」の2パターンを対比して説明する
- 「使い方は簡単！3ステップ」を早い段階で入れる
- ライブラリ機能は独立したスライドで丁寧に説明する
- β版・AIは参考である旨を最後に1枚入れる
- 開発用語や内部実装名は使わない
- トーンは親しみやすく、押し付けがましくない

【出力形式】
スライド番号ごとに
## スライドN：タイトル
- 本文箇条書き
- スピーカーノート：
```

### プロンプト B：短時間版（10枚・5分）

```
ソースを要約し、5分で話せる「洋楽AIチャットの楽しみ方」プレゼンを
全10スライドで作成してください。

必須：2つの楽しみ方（みんなで／ひとりで）、3ステップ、同時視聴、
AIサポート（解説と@質問）、ライブラリ、β版の注記。

各スライドはタイトル＋箇条書き3点＋短いスピーカーノートのみ。
```

### プロンプト C：主催者・イベント案内向け

```
「洋楽AIチャットの楽しみ方」を、部屋の主催者が友人を誘うときの
説明資料（12〜15スライド）として作成してください。

重点：会の立て方、URL選曲、ライブラリ選曲、順番制・同時視聴のルール、
聴き専の人への配慮、お題ミッションの使い方、同時主催2部屋まで、
鍵・オーナー機能の概要。

参加者向けの「マナー」は深掘りしすぎず、楽しさ中心で。
```

### プロンプト D：Google スライド貼り付け用（テーブル）

```
上記プレゼンを、Googleスライドにコピペしやすい表形式で出力してください。

列：スライド番号 | タイトル | 本文（改行区切り箇条書き） | スピーカーノート | 推奨ビジュアル
```

### プロンプト E：FAQ スライド追加

```
「楽しみ方」プレゼンの末尾に、よくある質問スライドを5問分追加してください。

例：ゲストでも使える？／スマホだけでも？／洋楽以外の曲は？／
AIに何でも聞いていい？／お金はかかる？

回答はソースの内容に忠実にし、不明な点は「β版のため変更あり」と書く。
```
