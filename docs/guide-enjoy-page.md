# 洋楽AIチャットの楽しみ方

**Music AI Chat** — `/guide/enjoy`

> 本ドキュメントは、Web ページ [`/guide/enjoy`](https://musicai.jp/guide/enjoy) の **2026年6月時点** の構成・文言を Markdown に起こしたものです。  
> 実装のソースは `src/lib/guide-enjoy-features.ts`（表示は `src/components/guide/GuideEnjoyFeatureList.tsx`）。

---

YouTube の洋楽を、チャットルームで同時に聴きながら交流できるサービスです。まずは 3 ステップで始められます。

**注記:** 本サービスは β版のため、機能の追加・変更・一時停止がある場合があります。  
バッジ **β版**＝試験提供中、**ログイン**＝ログインが必要、**任意**＝ゲストでも利用可、を示します。

---

## 楽しみ方の2パターン

### みんなでワイワイ

友達や初対面の参加者と同じ部屋に入り、URL やライブラリで順番に選曲。曲解説をきっかけに感想を交わし、クイズやお題で盛り上がる。

### ひとりでじっくり

自分で会を立てて一人入室。好きな曲を流し、AI 解説を読みながら @ で深掘り質問。お気に入りやマイリストに残して次回につなげる。

---

## 使い方は簡単！3ステップ

| STEP | 内容 |
|------|------|
| **1** | **チャットルームを選んで入室** — トップページから開催中の部屋に入るか、ログインして自分で会を立ち上げます。ゲストでも参加できます。 |
| **2** | **聴きたい曲を選曲** — YouTube の URL を発言欄に貼って送信するのが基本です。ライブラリから曲を選ぶ方法もあります。→ [選曲のしかた](/guide/first-song) |
| **3** | **曲の動画（PV 等）を視聴** — 部屋の参加者みんなで同じタイミングに再生されます。視聴しながらチャットで感想を伝え合えます。 |

---

## 選曲方法

順番に曲を流していく——**みんなで回す DJ ブースを再現できる**のが、洋楽AIチャットの大きな魅力です。次の 3 つが選曲の基本。ほかにも、番が回るまでの準備や、流れを意識した楽しみ方があります。

### 基本の3つ（タブ切り替え）

| タブ | 内容 |
|------|------|
| **YouTube URL** | **YouTube で URL をコピーしてスタンバイ** — PC では別タブ、スマホでは YouTube アプリなど別アプリでお好みの曲を検索し、URL をコピーしておきます。自分の番になったら発言欄に貼って送信するのが基本です。→ [選曲のしかた（PC）](/guide/first-song) |
| **ライブラリ** | **ライブラリから「選曲」ボタンで一発選曲** — 部屋内のライブラリで曲やアーティストを探し、一覧の選曲ボタンからそのまま部屋に流せます。YouTube を行き来せず、アプリ内で完結します。 |
| **マイリスト** | **マイリスト・お気に入りに候補曲をストック** `[ログイン]` — マイページのマイリストやお気に入りに、あらかじめ次に流したい曲を登録しておけます。 |

### 基本操作

- **自分の選曲が終わってから、次の番までに次曲をセット**  
  順番制のため、いま流している曲を聴きながら次の一曲を決めておく時間があります。候補リストに溜めておく方法も使えます。

- **選曲者と部屋オーナーは、再生中の曲をスキップできる**  
  自分が選んだ曲の再生中、または部屋のオーナーは、必要に応じて次の曲へ進められます。長尺のライブ映像などで使う基本操作です。

### 選曲の醍醐味

他の参加者の選曲にインスパイアされることも多く、部屋の流れを意識した選曲を楽しむのも醍醐味です。次の自分の番までに曲を探す**緊張感とワクワク感**も、音楽チャットならではの魅力のひとつ。お題プレイリスト・ミッションがあるときは、テーマに合う曲を予習して用意しておくのも、事前の楽しみ方のひとつです。

## チャットルームならでは楽しみ方

同時視聴とチャットが一体になっているのが、このサービスのいちばんの特徴です。

| 項目 | 説明 |
|------|------|
| 選曲は順番制で、再生中は参加者同時視聴 | 流れている曲は全員が同じタイミングで聴きます。次の曲は順番に選んでいく使い方が基本です。 |
| 視聴しながらテキスト入力で会話 | 再生中の曲への感想や雑談を、その場でやり取りできます。→ [チャットのマナー](/guide/chat) |
| 趣向や年代の異なるユーザーとの出会い | 参加者それぞれの選曲が会話のきっかけになり、普段触れないジャンルや年代の洋楽にも自然に出会えます。 |
| 選曲せず、視聴と会話だけの参加も可能 | 聴き専で様子を見たり、感想だけ書いたりする入り方もできます。慣れてから選曲に参加しても大丈夫です。 |

## マルチデバイスとユーザー登録

使う端末やログインのしかたを選べます。

| 項目 | 説明 |
|------|------|
| PC・タブレット・スマホで利用可能 | ブラウザから利用できます。スマホでは YouTube の共有から URL をコピーして選曲する流れも用意しています。→ [スマホでの選曲](/guide/first-song-mobile) |
| メールアドレス、または Google 認証でユーザー登録 `[ログイン]` | 登録するとお気に入り・選曲履歴・マイリストなどが残り、次回以降も引き継げます。 |
| ユーザー登録しないでゲスト参加も可能 `[任意]` | ログインしなくても部屋に入ってチャット・視聴できます。 |

## もっと楽しむ

タブを切り替えて、機能をカテゴリごとに確認できます。

### 2つのオリジナル AI がサポート

洋楽AIチャットには、役割の異なる 2 種類のオリジナル AI があります。どちらも部屋の体験を豊かにします。

#### AI キュレーター

**選曲の進行をナビゲートし、解説・質問・おススメ曲を提案する AI**

システム側の AI が、選曲の順番や進行を案内します。曲が流れるたびに短い曲解説を出し、@ 付きの質問に答え、次に聴く候補（おススメ曲）を提案することもあります。場の流れをつくる「司会・解説役」です。

→ 詳細は下記 **タブ: AI**

#### AI エージェント `[β版]`

**ユーザーと同じ立場で選曲に参加し、会話で場を盛り上げる AI**

人間の参加者と同じように、順番が回ってきたら曲を選ぶこともあります。会話に合いの手を入れたり、参加者が少ないときの相棒として、部屋の空気をやわらげます。キャラクター性のある「一緒に楽しむ仲間」です。

→ 詳細は下記 **タブ: エージェント**

---

### タブ: AI — AI キュレーター（便利な AI サポート）

選曲の進行ナビ、曲解説、@ 質問、おススメ曲提案など、AI キュレーターがサポートします。

| 機能 | 説明 |
|------|------|
| 選曲の順番は AI が先導 | 曲が切り替わるたびに AI が進行を補助し、場が止まりにくい流れをつくります。候補リストで次の曲を溜めておくこともできます。 |
| 曲の解説を AI が短いコメントで紹介 | 選曲後に背景や聴きどころを短く紹介します。会話のきっかけや、知らない曲との出会いに役立ちます。→ [AI について](/guide/ai) |
| 発言の先頭に @ を付けると AI に質問できる | 洋楽に関する質問に AI が答えます。おすすめの曲やアーティストのことなど、音楽の話題を広げられます。→ [質問のしかた](/guide/ai) |
| いま流れた曲をもとに、次に聴く候補を AI が提案 `[β版]` | 曲の流れに合わせて、次に聴く候補を AI が提案します。ひとりで新しい曲を開拓したいときにも向いています。 |

---

### タブ: エージェント — AI エージェント（愉快な参加型 AI）

ユーザーと同じ立場で選曲に参加し、会話に入って場を盛り上げる AI エージェントです。

| 機能 | 説明 | |
|------|------|---|
| ユーザーに交じり AI エージェントも選曲参加 | 会の流れに合わせて、AI エージェントが次の曲候補を提案することがあります。 | `[β版]` |
| 時々ユーザーの会話に AI エージェントも入る | 会話の合いの手や補足として、AI エージェントが発言することがあります。 | `[β版]` |
| ユーザーが一人のときに相棒として楽しめる | 参加者が少ない部屋でも、AI エージェントがいると一人で聴く時間が味わいやすくなります。 | `[β版]` |

---

### タブ: 視聴中 — 曲を視聴しながら楽しめる機能

聴いている最中や直後に、クイズや曲情報を楽しめます。

| 機能 | 説明 |
|------|------|
| 曲解説のあと、同じ曲の文脈で三択クイズが出題 `[β版]` | 条件を満たす曲では、曲解説のあと三択クイズが出ることがあります。みんなで答えて正解発表を待つ参加型の楽しみ方です。 |
| 曲とアーティストの基本情報を表示 | 再生中の曲やライブラリから、アーティスト・曲名・年代・スタイルなどの情報を参照できます。 |
| 視聴履歴と年代・スタイル分布で選曲の流れが分かる | 途中参加でも、部屋の視聴履歴や分布表示からこれまでの流れを把握しやすくなります。 |

---

### タブ: 共同 — ユーザー同士で共同作業

テーマに沿って、みんなでプレイリストを育てる楽しみ方です。

| 機能 | 説明 |
|------|------|
| お題（クリスマス等）プレイリスト・ミッション `[β版]` | マイページでお題を選び、曲を登録していくミッションです。部屋で「お題曲送信」すると、お題向けの AI 講評も出ます。 |

---

### タブ: ライブラリ — 豊富な曲ライブラリ

洋楽の曲データベースを、部屋内からそのまま探して選曲できます。

| 機能 | 説明 |
|------|------|
| キーワードで曲やアーティストを検索 | ライブラリの検索欄から、登録済みの曲やアーティストを探せます。 |
| アーティスト別の曲一覧から選べる | アルファベット索引（A–Z）でアーティストを選び、曲一覧から次の一曲を決められます。 |
| 選んだ曲をそのまま再生して選曲できる | 一覧から曲を選ぶと、部屋の同期再生がその曲に切り替わります。YouTube を行き来せず、アプリ内で完結します。 |

---

### タブ: マイページ — 自分用に記録できるマイページ

ログインすると、聴いた曲や好みを自分用に残せます。

| 機能 | 説明 |
|------|------|
| 選曲した曲の履歴保存 `[ログイン]` | 部屋で貼った・流した曲の記録を、あとから振り返れます。 |
| お気に入りやマイリストへの曲登録 `[ログイン]` | 気に入った曲をお気に入りやマイリストに保存し、整理・書き出しができます。 |
| 公開プロフィールで自己紹介 `[ログイン]` | 一言コメントや好きなアーティストなどを登録できます。 |

---

### タブ: オーナー — その他オーナー機能

部屋の主催者・オーナー向けの運営機能です。

| 機能 | 説明 |
|------|------|
| 主催部屋の名前・PR 文の掲載 `[ログイン]` | 部屋のタイトルや一言紹介を設定できます。トップの開催一覧にも反映されます。 |
| 部屋に鍵をかけて新規参加を制限 `[ログイン]` | 開催中の会で新規参加を締め切る設定ができます。常連だけで続けたいときなどに使えます。 |
| 迷惑ユーザーの強制退出 `[ログイン]` | チャットオーナーは、マナー違反などの参加者を部屋から退出させることができます。 |
| 登録ユーザーは一人 2 部屋まで開催可能 `[ログイン]` | 同時に主催できる会は、1 アカウントあたり最大 2 部屋までです。→ [主催の上限など](/guide/service) |
