## 0. 工程マスター（いま → クレジット販売開始）

依存関係の正順。**VO 契約前に Stripe 本番販売は始めない**（特商法の所在地・電話が揃ってから）。

```
[いま] VO 申し込み中
   ↓
[来週目安] VO 契約・050 取得
   ↓
[直後] 特商法ページに住所・電話を掲載（コード更新）
   ↓
[並行可] 開業届（事業所＝VO）· Stripe アカウント作成（KYC）
   ↓
[開発] Stripe Checkout + Webhook + 購入 UI（クレジット販売）
   ↓
[公開] 本番で ¥500／¥1,000 チャージ開始
```

| # | 工程 | 目安 | 状態 | 成果物・依存 |
|---|------|------|------|----------------|
| **1** | **バーチャルオフィス** | 申し込み済 → **来週契約** | 進行中 | 住所・郵便・（できれば）050。特商法「所在地」に使えるか契約時に再確認 |
| **2** | **050 番号** | VO と同時 or 直後 | 未 | 転送→本人携帯。特商法「電話」掲載用（090 は載せない） |

| **4** | **開業届** | VO 住所確定後 | 未 | 事業所所在地＝VO。Stripe・税と整合 |
| **5** | **Stripe アカウント** | 開業届と前後可 | 未 | 本人・自宅・個人口座・事業所＝VO。**本番販売の前提** |
| **6** | **クレジット販売システム** | Stripe KYC 通過後〜並行開発可 | 段階1のみ済 | Checkout（¥500＝20 / ¥1,000＝40）· Webhook で残高加算 · 購入 UI |

## 4. バーチャルオフィス（VO）選定

### 4.1 富山 vs 東京・大阪

**料金最優先なら、在住地（富山）にこだわる必要は薄い。** 大手 VO の東京（または大阪）エントリープランを比較するのが無難。

| 観点 | 富山 | 東京・大阪（大手 VO） |
|------|------|------------------------|
| 特商法の所在地 | 事業者次第で可 | 事業者次第で可 |
| 月額 | 選択肢少なく割高になりがち | 競争で最安帯が出やすい |
| 郵便転送 | 事業者次第 | 運用成熟（スキャン・アプリ等） |
| 050 | 要確認 | セット・オプションが豊富 |
| 実際に行く | 近い | 年数回なら出張コストの方が高いことも |

富山が向くのは、**月1回以上自分で郵便を取りに行く**・**地元会議室を頻繁に使う**など、対面前提のとき。

### 4.2 契約前チェックリスト

1. **特定商取引法の「所在地」表記に使えるか**（規約・FAQ に明記）
2. 郵便：転送月何通まで、スキャン、保管、追加料金
3. 050：同社契約か別契約か
4. 最低契約期間・解約金
5. Stripe・開業届で同じ住所を使えるか
6. 開業届を VO 住所で出す場合の**税務署管轄**（富山在住でも可。不明なら税理士に一言）

### 4.3 郵便物のあて名（VO 側・サイト外）

事業者の指定フォーマットを最優先。一般的な個人＋屋号:

1. **前橋雄治** 様（いちばん無難）
2. **前橋雄治（洋楽AIチャット）** 様
3. **洋楽AIチャット　前橋雄治** 様

- 特商法の「販売事業者」と**完全一致は不要**（届けばよい）。
- **Stripe・開業届・VO 登録名**は揃えると後から混乱しにくい。
- 「洋楽AIチャット事務局」のみのあて名は、個人契約 VO では受け取れないことがある。

### 4.4 050 番号（特商法掲載用）

- **妥当**。小規模 Web サービスで一般的。
- 条件：**掲載番号に実際に電話がつながる**こと。050 → 本人携帯転送・留守電がおすすめ。
- 特商法に **090 個人番号を載せる必要はない**。

## 5. Stripe（VO 契約とは別）

Stripe は **本人確認（KYC）・入金** のため、特商法の「見せ方」と分けて考える。

| | 特商法（公開） | Stripe（非公開・本人確認） |
|--|----------------|----------------------------|
| 目的 | 購入者への事業者表示 | 入金・本人確認 |
| 氏名 | 前橋雄治（屋号：洋楽AIチャット） | **前橋雄治（本人）** |
| 事業所住所 | VO 住所 | **VO 住所**（開業届と同じ） |
| 本人住所 | 載せない | **自宅**（本人確認用） |
| 電話 | 050（問い合わせ） | **本人携帯**（SMS 認証等） |
| 口座 | 載せない | **本人名義の個人口座**（事業専用口座は必須ではない） |

### 5.1 整合のルール

```
【公開】特商法・サイト
  販売事業者: 前橋雄治（個人事業主・屋号：洋楽AIチャット）
  所在地:     VO 住所
  電話:       050
  メール:     musicai@gol.com

【非公開】Stripe・税務（本人確認）
  代表者:     前橋雄治
  事業所:     VO 住所  ← 開業届・特商法と揃える
  本人住所:   自宅
  電話:       本人携帯
  入金口座:   個人名義銀行口座
```

### 5.2 やらないこと

- Stripe に虚偽の住所・他人名義口座（アカウント停止リスク）
- 特商法に自宅・090 を載せる（VO を取る意味が薄れる）
