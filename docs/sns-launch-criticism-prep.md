## 2. 四大論点

### 2.1 AI解説が有料

**想定叩き**: チャットなのに金取る／お試し後ゴリ押し／原価より高いぼったくり。

**事実（強み）**

- 同時視聴・選曲・通常チャットは **無料のまま**
- 有料は AI（曲解説・@ 等）のみ。お試しあり。プリペイド明示
- 価格正本: ¥500＝20クレジット · ¥1,000＝40クレジット（1曲＝1 · @＝0.5）

**定型**

> 音楽の同時視聴とチャットは無料です。課金はクラウドAIの曲解説・質問など、原価のかかる機能だけです。お試し後も、AIなしならずっと無料で使えます。

**準備チェック**

- [ ] LP・X固定・FAQ の先頭に無料／有料の境界
- [ ] 「原価目安」を前面に出しすぎない（ぼったくり燃料になりやすい）
- [ ] 枯渇後 UI が課金圧に見えないか
- [ ] 価格変更時の告知型を決める

### 2.2 YouTube の音源に便乗

**想定叩き**: YouTubeで稼いでる／海賊版／権利者無視。埋め込み＝違法に見えがち。

**説明軸（守り）**

- 再生は YouTube **公式埋め込み（IFrame）**。音声抜き・別配信・広告ブロックはしない
- 収益は **AI機能の対価**。動画配信の再販ではない
- 違法アップロードの助長は禁止（`/guide/music`）

**定型**

> 曲の再生はYouTubeの公式埋め込みです。当サービスが音源を独自配信しているわけではありません。有料なのはAIの解説・対話機能です。

**注意**: 「YouTubeが認めている」と断定しすぎない。正しいのは「公式埋め込みの範囲で利用／各規約に従う」。

**準備チェック**

- [x] FAQ「YouTubeとの関係」（§4 / `/guide/faq`）
- [ ] 宣伝で「公式音源を提供」「ストリーミングサービス」等の誤認語を使わない（運用ルール化）
- [ ] 権利者・レーベル問い合わせの返信テンプレ＋停止手順
- [ ] AI解説の誤り・断定表現の抑制（運用＋既存出力ポリシー）
- [ ] （任意）弁護士への一言確認

### 2.3 主催者が怪しい

**想定叩き**: 特商法スカスカ／個人で逃げられる／「事務局」っぽい嘘。

**現状メモ（コード正本 `commercial-transactions-operator.ts`）**

| 項目 | 公開状況（2026-07-25 時点） |
|------|------------------------------|
| 屋号・個人事業 | 表示（氏名はフラグ次第） |
| 個人氏名 | `PERSONAL_NAME_PUBLISHED = false`（請求時開示方針） |
| 所在地（VO） | `ADDRESS_PUBLISHED = true` |
| 電話 | `PHONE_PUBLISHED = false`（050 取得後） |
| メール | 公開 |

**定型**

> 個人事業として運営しています。販売事業者・連絡先は特定商取引法に基づく表示に記載しています。音楽チャット自体は無料で、有料はAI機能のクレジットです。

人格攻撃には長文反論しない。**特商法 URL を貼って終わり**が安全。

**準備チェック**

- [ ] 氏名公開タイミング（§3.1）
- [ ] 050 取得・掲載（目安 2026-09 以降）
- [x] About／「なぜ作ったか」（`/guide/about`）
- [ ] 問い合わせ SLA（例: 2営業日）を特商法かガイドに書く
- [ ] 返金・キャンセル条件の明確化（有料開始と同時）
- [ ] 運営 SNS で障害・マナー・課金説明も出す

### 2.4 洋楽限定なのはなぜ？

**想定叩き**: 邦楽差別／日本人アーティスト軽視。

**説明できる理由（サイトメッセージ正本: `/guide/about`）**

1. YouTube での掲載率が相対的に高く、同時視聴の土台が揃いやすい
2. タイトル等の記載が定型的で、正しい曲情報を取りやすい
3. AI で言語の壁を越え、解説を日本語で届けやすい → 洋楽への距離が近くなる
4. 1990〜2000年代をひとつの頂点に、押され気味の洋楽をいま一度盛り上げたい
5. 熱狂的ファンの懐かしさ・当時の楽しさの共有
6. 新旧ファン・世代とジャンルを超えた化学反応
7. 主催者はいち洋楽ファン。既存チャットでの洋楽会主催経験 → より機能的な場をつくりたい
8. **これから**: 邦楽曲解説は周辺環境整理のうえ順次／将来は多言語化・同時翻訳も視野

**定型（短文・SNS）**

> 邦楽を否定しているわけではありません。YouTube掲載や曲情報の取りやすさ、AI解説、懐かしさや世代交流のため、いまは洋楽特化です。詳しくは → /guide/about

**避ける言い方**: 「邦楽はAI向きじゃない」「日本の曲がダメ」。

**サイト掲載**

- 全文メッセージ: `/guide/about`（`AboutServiceMessage`）
- FAQ 要約: `/guide/faq` Q4 → about へリンク
- トップ紹介文から「なぜ洋楽か・運営の思い」へリンク

## 4. (A) サイト掲載用 FAQ（正本）

> **実装**: `src/app/guide/faq/page.tsx`（`/guide/faq`）  
> 文面を直すときは **本節とページを同時更新**。

### Q1. 何が無料で、何が有料ですか？

音楽の同時視聴（YouTube）、部屋での選曲、通常のチャットは無料です。  
有料なのは、クラウドAIを使う機能（曲のAI解説、@ での質問など）です。登録後のお試し枠があり、枠を使い切ったあとも、AIなしの選曲・チャットは無料のまま使えます。  
料金の詳細は [AI利用料金・クレジット](/guide/ai-pricing) をご覧ください。

### Q2. YouTube の音楽で稼いでいるのですか？音源の違法配信では？

いいえ。曲の再生は YouTube の公式な埋め込みプレイヤーを利用しています。当サービスが音源ファイルを独自に配信したり、音声だけを抜き出したりするものではありません。  
有料でお支払いいただくのは、AIによる解説・対話などの機能です。動画・音声の利用は YouTube 等の各サービスの規約に従います。違法アップロードの助長になる行為は禁止しています（[曲・コメント](/guide/music)）。

### Q3. 運営は誰ですか？怪しくないですか？

洋楽AIチャットは個人事業として運営しています。販売事業者・所在地・連絡先などは [特定商取引法に基づく表示](/commercial-transactions) に記載しています。お問い合わせは同ページのメールアドレスまでお願いします。  
本サービスは Google / YouTube 等の公式サービスではありません。独立して運営しているコミュニティ型の音楽チャットです。

### Q4. なぜ洋楽だけなのですか？邦楽はダメなのですか？

邦楽を否定しているわけではありません。YouTube での掲載率や曲情報の取りやすさ、AI で言語の壁を越えた解説が届けやすいこと、懐かしさや世代とジャンルを超えた交流の場をつくりたいことなどから、いまは洋楽に特化した AI 解説・会話の場として設計しています。邦楽の曲解説も、周辺環境を整えたうえで順次公開していく方針です。詳しい理由と運営の思いは [このサービスについて](/guide/about) をご覧ください。

### Q5. AIの解説は正しいですか？

AIの回答や解説には誤りが含まれることがあります。重要な事実は、公式サイトや信頼できる情報源でご確認ください。チャート順位や「バズった」等の断定は、根拠がない場合は控える方針で改善を続けています。

## 6. 炎上時オペレーション
