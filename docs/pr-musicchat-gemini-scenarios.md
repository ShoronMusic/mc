## 1. 一言・ポジショニング

| 軸 | 内容 |
|----|------|
| **一言** | YouTube の曲を、参加者みんなで**同じタイミング**で聴きながら、**リアルタイムチャット**で交流するサービス。 |
| **メタファー** | 「みんなで同じ曲をかけながら語るオンライン部屋」／「離れていても一緒に聴いている感覚」 |
| **何ではないか** | ラジオの一方通行でも、ビデオ会議でも、AI 解説サロンでもない。**同期視聴 × 人同士のチャット**に特化。 |
| **誰向け** | 友達・コミュニティ・ファン同士で邦楽／洋楽を一緒に聴きたい人。AI なしでシンプルに楽しみたい人。ゲストでもすぐ入室したい人。 |
| **ファネル上の役割** | 集客・気軽な入口（完全無料）。深掘り・AI 解説は姉妹サイトへ任意導線。 |

## 2. 特徴・魅力（整理）

### 2.1 コア魅力（スライドで最優先）

1. **同期視聴** — 同じ曲・同じタイミング。サビで一緒に盛り上がれる。
2. **リアルタイムチャット** — 聴きながら感想・雑談。離れていても「いま」が共有される。
3. **邦楽も洋楽も OK** — ジャンル・言語を問わず YouTube で選曲できる幅の広さ。
4. **完全無料** — 登録でもゲスト参加でも、同期視聴＋チャットの本編は無料。
5. **かんたん参加** — PC・スマホ対応。部屋を選んで入室／主催はログインで。

### 2.2 体験の流れ（ユーザーストーリー）

1. **https://www.musicchat.jp/** を開く  
2. 開催中の部屋に入る、またはログインして**部屋を主催**する  
3. YouTube の曲を選び、**全員の再生が同期**する  
4. チャットで感想・雑談  
5. （任意）同じアカウントで姉妹サイト・洋楽AIチャットも利用（マイリスト等共通）

### 2.3 差別化の言い方（フレーズ集）

| 狙い | フレーズ例 |
|------|------------|
| 同時性 | 「ラジオではなく、**同じタイムコードで笑える・語れる**」 |
| シンプル | 「AI なし。**聴く × 話す**に集中」 |
| 邦楽 | 「邦楽も洋楽も、**みんなの選曲でつながる**」 |
| 無料 | 「まずは気軽に。**完全無料**で一緒に聴く」 |
| 距離 | 「離れていても、**同じ部屋で同じ曲**」 |
| ドメイン | 「はじめの一歩は **musicchat.jp**」 |

### 2.4 姉妹サイトとの対比（1 スライド分・誤解防止）

| | **ミュージックチャット**（本資料） | **洋楽AIチャット**（姉妹） |
|--|-----------------------------------|---------------------------|
| URL | **https://www.musicchat.jp/** | https://www.musicai.jp/ |
| 訴求 | 同期視聴 × チャット | 同期視聴 × チャット × **AI 解説** |
| AI | **なし** | あり（進行・解説・`@` 等） |
| 曲種の打ち出し | **邦楽・洋楽 OK** | 洋楽中心 |
| 料金の打ち出し | **完全無料** | AI 利用はお試し後に有料方針 |
| アカウント | 同じ Google／メールで両方使える。マイリスト等共通。同時に開いても可 | 同左 |

### 2.5 誠実さ・β版

- β版のため、機能・UI は改善中である旨を 1 文入れてよい。  
- YouTube・著作権の範囲内での視聴が前提。  
- AI の誤情報を心配する層には「**人同士の会話が主役**」と明言すると安心材料になる。
